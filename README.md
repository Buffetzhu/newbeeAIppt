# Let's Play AI

面向非 IT 朋友的 AI 科普分享材料。

## 当前产物

- `AI-share-web/index.html`：网页预习版原型，可直接用浏览器打开。
- `AI-share-web/assets/`：网页使用的高质量配图与动效素材。
- `AI-share-web/AI科普分享-Apple科技风-V3.1优化版.pptx`：当前 PPT 版本。
- `AI科普分享-V3.1逐页讲稿大纲.md`：逐页讲稿与内容大纲。
