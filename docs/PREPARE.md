# AI 分享预习下载清单

请在分享开始前提前下载或收藏下面几个文件，现场网络不稳定时也能跟上。

## 必下

- `ai-share-v41.pdf`：适合手机、平板、电脑快速预习。
- `ai-share-v41.pptx`：如果想看完整 PPT 或做笔记，可以下载这一版。

## 可选

- `agent.md`：给对 AI Agent / Playbook / Script 工作流感兴趣的朋友阅读。不是必读，分享现场会用更通俗的方式讲。

## 建议提前准备

- 一个你常用的 AI 工具账号，例如豆包、元宝、Kimi、ChatGPT、Claude、DeepSeek 等。
- 如果想跟着看实战，可以提前安装 VS Code。
- 准备一个你自己想用 AI 解决的小问题：整理文件、做表格、写报告、做网页、做小工具都可以。

## 预习方式

不用逐字读完。建议先快速看三件事：

1. AI 为什么最近两年突然变强。
2. 常见黑话：Token、RAG、Agent、MCP、API、CLI。
3. 最后实战部分：AI 怎么从聊天变成帮你做事。
