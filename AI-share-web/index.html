Part 01 · 看懂 AI

先把黑话翻译成人话。

不需要先学数学，也不需要记住所有名词。先抓住 6 个基本概念，就能听懂大多数 AI 讨论。

AI 不是“懂一切”，而是在上下文里生成下一步。

把它当成一个有强大模式识别能力的协作者，但不要把它当成事实权威。

Token 是它的阅读单位。
上下文是它当前能看到的工作台。
Prompt 是你交给它的任务说明。
模型被训练出的能力体，不是传统软件功能表。
TokenAI 的阅读单位，影响成本、速度和容量。
上下文AI 当前能看到的信息窗口。
Prompt目标、背景、约束和输出格式。
RAG先检索资料，再基于资料回答。
幻觉像真的答案，但事实可能错。
Part 02 · 选对工具

不要按排行榜选，按任务选。

工具更新太快，排名很快过期。更稳定的判断方式是：我要解决什么任务，给它什么资料，结果怎么验证。

工具生态已经从聊天框扩展到工作流。

问答、搜索、写作、图片、视频、代码和自动化，最好按场景分层，而不是混在一个榜单里。

问答GPT / Claude / Gemini
中文长文Kimi / DeepSeek / 豆包
代码Codex / Claude Code / Cursor
Agent小龙虾 / 爱马仕 / WorkBuddy

Agent 是从“回答问题”到“执行任务”的转折点。

它能观察环境、拆任务、调用工具、执行步骤、回报结果。能力更强，也更需要权限控制。

浏览器 Agent：找页面、点按钮、填表。
电脑 Agent：批量处理文件、操作应用。
开发 Agent：读项目、写代码、跑测试。
Part 03 · 把 AI 用起来

从会问问题，到让它帮你干活。

真正有用的 AI，不是回答得漂亮，而是能把你的重复劳动变成可复用流程。

马拉松报名

找入口、准备字段、减少临场手工时间，把抢时间变成流程准备。

批量处理文件

让 AI 扫描、分类、重命名、生成目录和处理摘要。

开发小工具

用自然语言做一个报名信息助手，从需求到界面再到可用功能。

Q&A

下次遇到 AI 工具，先问三个问题。

它替我省掉哪段重复劳动？
我能给它什么上下文？
结果怎么验证？
